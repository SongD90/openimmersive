# OpenImmersive Translator

A browser extension that translates web pages in place, showing the translation alongside or instead of the original text.

## Display modes

**Display mode**:
The way a translated page is presented to the reader.
_Avoid_: Layout, view type

**Bilingual**:
The display mode where each translation sits directly beneath its original paragraph on a single page.
_Avoid_: Side-by-side, dual, parallel

**Replace**:
The display mode where the translation takes the place of the original text, showing only the translated language.
_Avoid_: Translation only, overwrite

**Split view**:
The display mode where the window is divided into two halves, the original page on one side and a fully translated copy on the other.
_Avoid_: Side-by-side, dual page, parallel view

**Original pane**:
The half of a split view that shows the page as published.
_Avoid_: Source pane, left pane

**Translated pane**:
The half of a split view that shows the translated copy of the page.
_Avoid_: Target pane, right pane

**Scroll sync**:
Keeping the two panes of a split view at the same place in the page by aligning matching blocks, not by matching pixel or percentage positions.
_Avoid_: Linked scrolling, scroll lock

## Translation

**Block**:
A piece of page text (a paragraph, heading, list item, table cell or similar) that is translated as one unit.
_Avoid_: Paragraph, segment, chunk
